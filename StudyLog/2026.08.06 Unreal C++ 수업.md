
# 1.  지난시간 실습 풀이
## 풀 정책 구현하기
나의 방식은 사용중인 액터 목록을 맵으로 만들어서 키를 객체, value를 시간으로 저장해서 시간을 기준으로 오래된 액터를 판별해서 반환
수업 내용의 경우 연결리스트로 추가적인 추가적인 정보를 저장. 기본적으로 큐와 비슷하게 사용하는데 중간 삭제를 빠르게 하기 위해서 Map을 추가적으로 생성해서 매핑. 이 경우 기본적으로는 풀에서 꺼내온 액터를 Tail에 삽입하기 때문에 가장 오래된 Actor는 Head에서 가져오면 된다. 하지만 중간에 있는 액터가 먼저 return 혹은 삭제될 수 있기 때문에 빠른 탐색을 위해서 Map에 키를 액터로, 값을 연결리스트의 노드로 매핑해 해당 액터를 리스트에서 빠르게 찾아온다.

## Cpp에서 DataTable 사용하기

적이 죽으면 아이템을 떨어뜨리는 기능을 구현할 때 아이템이 한 종류라면 해당 액터 또는 에셋을 변수로 들고 있어도 상관 없다. 하지만 여러 아이템들 중에서 골라서 떨어뜨려야하면 (드랍 테이블이 필요하면) 에셋을 전부 들고 있다가는 가독성, 유지보수, 메모리 측면 모두에서 좋지 않은 결과를 가져온다. 이를 효과적으로 해결하기 위해서 데이터 테이블을 cpp에서도 사용해보자

```cpp file:EnemyCharacter.h
	// 변수로 들고있을 드랍테이블
	UPROPERTY(EditAnywhere, BlueprintReadOnly)
	TObjectPtr<UDataTable> ItemDropTable;
```




```cpp file:EnemyCharacter.cpp
// 실제 아이템을 떨어뜨리는 부분
void AEnemyCharacter::DropItem()
{
	if (IsValid(ItemDropTable))
	{
		float RandNum = FMath::FRandRange(0.0, 1.0);
		// DropTable의 Row를 순회
		for (const auto& [Key, Value] : ItemDropTable->GetRowMap())
		{
			// Value는 Row의 주소를 uint8*형식의 바이트 코드로 변환해서 들고있기 때문에
			// 포인터의 타입을 변환해준다
			// 이렇게 추출한 Row로 데이터를 사용하면 된다.
			FItemDropTableRow* DropTableRow = reinterpret_cast<FItemDropTableRow*>(Value);
			if (!DropTableRow) continue;

			UGameInstance* GameInstance = GetGameInstance();

			float currentItemSpawnRate = DropTableRow->DropRate;
			if (currentItemSpawnRate < RandNum)
			{
				FActorSpawnParameters SpawnParam;
				SpawnParam.Owner = nullptr;
				SpawnParam.ObjectFlags = RF_Transient;
				FTransform NewTransform = GetTransform();
				FVector NewLocation = NewTransform.GetLocation();
				NewLocation.X += FMath::FRandRange(-100.0, 100.0);
				NewLocation.Y += FMath::FRandRange(-100.0, 100.0);
				NewTransform.SetLocation(NewLocation);

				if (!GameInstance) continue;
				UObjectPoolSubsystem* SubSystem = GameInstance->GetSubsystem<UObjectPoolSubsystem>();
				APickupWeapon* SpawnedWeaponPickUp = SubSystem->Spawn(PickUpWeponActor, NewTransform);
				SpawnedWeaponPickUp->Init(DropTableRow->DropItemAsset.LoadSynchronous());
			}
		}
	}
}
```
