
# 1.  지난 실습 풀이
## PickupBase 수정하기
내 실습 풀이와 유사 공통된 부분을 기본 클래스에 작성한다. 픽업 아이템의 움직임 처리의 대부분을 Base에서 하고 획득처리는 파생클래스에서 하도록 구성

```cpp file:PickupBase.cpp
// 타이머 기반으로 빨려들어오는 모션이 끝나면 핸들만 초기화하고 파생클래스에서 알아서 하도록
void APickupBase::MoveToplayerWithTimerDone()
{
	GetWorldTimerManager().ClearTimer(PickupEffectTimerHandle);
}
```

```cpp file:PickupWeapon.cpp
// 무기 픽업에서 실제 획득처리
void APickupWeapon::MoveToplayerWithTimerDone()
{
	Super::MoveToplayerWithTimerDone();
	if (Target.IsValid() )
	{
		IWeaponUserInterface::Execute_EquipWeapon(Target.Get(), WeaponData.Get());
		if (UGameInstance* GameInstance = GetGameInstance())
		{
			UObjectPoolSubsystem* SubSystem = GameInstance->GetSubsystem<UObjectPoolSubsystem>();
			SubSystem->ReturnPool(this);
		}
	}
}
```

# 2. 인벤토리 widget 만들기
- 캔버스
	- 마우스 오버랩시 툴팁 나오는거 만들기에 용이

- 드래그 앤 드롭
	- 드래그시 들어갈 슬롯을 하나 만든다.
	- 그 슬롯이 마우스를 따라가도록

- UI는 만들어놓고 Visiblillity setting을 통해서 활성/비활성을 해야한다.
	- Create Widget, Add to Viewport를 반복적으로 하는것은 좋지 않다.

- 유용한 함수
	- Drag류는 바로 감지가 안됨
		- MouseButtonDown에서 감지를 켜야함
	- OnDragDetected
	- OnDragCancelled
	- OnDragEnter
	- OnDragLeave
