# 2. RPC (Remote Procedure Call)
- Replication으로는 부족한 커스텀 로직 실행용
	- Server RPC
		- 클라이언트가 서버에서 특정 로직을 실행하게 요청
		- 보안과 동기화가 주 목적
		- 몬스터 피격등 권한이 필요한 동작들
	- Multicast RPC
		- 서버가 모두에게 특정 로직을 실행하게 요청하는 것
		- 서버에서 특정 이벤트 전파가 주 목적
	- Client RPC
		- 서버가 특정 클라이언트에게 특정 로직을 실행하게 요청
		- 특정 클라이언트에서만 해야할 이벤트 전달
		- 운영자 귓말
- 주의사항
	- 가독성을 위한 접두어를 붙이는 것은 권장
		- `Server_, MultiCast_, Client_` 
		- 반환값은 반드시 void
		- 구현할 때 `_Implementation` 붙여서 구현
	- [[Connection]]이 필수!
	- 파라미터
		- 대부분의 파라미터는 사용이 가능
		- TSet, TMap의 경우 사용 불가
		- UObject나 그 자식 클래스는 사용시 조심
- 검증 함수
	- 핵이나 치팅 방지
	- `UFUNCTION(WithValidation)` 추가 후 `_Validate`를 붙인 함수를 만들면 됨.
- 신뢰성 설정
	- `UFUNCTION(Reliable), UFUNCTION(UnReliable)`
	- UDP기반의 통신이기 때문에 신뢰성이 필요하면 해당 키워드를 사용하자.

```cpp Title:RPC_Eaxmple hlt:24
// 서버에 투사체 발사를 요청하는 하는 함수
protected:
	UFUNCTION(Server, Reliable)
	void Server_Fire();
	
private:
	// 실제로 투사체를 발사하는 함수
	void Fire();
	
	
	
'''


void ANetTestCharacter03_RPC::Fire()
{
	// 내가 조종하고 있는지 확인
	if (IsLocallyControlled())
	{
		Server_Fire();
	}
}

void ANetTestCharacter03_RPC::Server_Fire_Implementation()
{
	// 서버가 실행하는 코드
	if (ProjectileClass)
	{
		FVector SpawnLocation = FireTransform2->GetComponentLocation();    
		const FVector FireDirection = GetActorForwardVector();
		const FRotator SpawnRotation = FireDirection.Rotation();

		FActorSpawnParameters SpawnParams;
		SpawnParams.Owner = this;
		SpawnParams.Instigator = GetInstigator();
		SpawnParams.SpawnCollisionHandlingOverride = ESpawnActorCollisionHandlingMethod::AlwaysSpawn;
		GetWorld()->SpawnActor<AActor>
			(
				ProjectileClass,
				SpawnLocation,
				SpawnRotation,
				SpawnParams
			);
	}
}
```
